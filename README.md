# Robot Drop Height Calculator

Impact robustness calculator for robotic joins e.g. in the case of falling.

# Access

Two options to access the calculator

- a) Use the github page link: https://dlr-rm.github.io/drop-height-calculator/drop_height_calculator.html 
- b) Clone the repository and open the file `docs/drop_height_calculator.html` in your browser.

# Background

This calculator is published alongside [1]. It mainly builds on the previous publications [2] and [3]:

- [1] A. Shu, K. Fruend, F. Beck, T. Ehlert, A. Kolb, N. Topalovic, C. Raschel, S. Wolf, M. Hutter, and J. Lee, "What Gear Ratio Makes QDD Actuators Robust Against Impacts? A Theoretical Limit and Interactive Tool for Legged Robots", IEEE-RAS International Conference on Humanoid Robots (Humanoids), 2026 (Accepted). [Preprint](https://elib.dlr.de/228065/) .
- [2] A. Shu, F. Loeffl, A. Kolb, K. Frund, D. Wandinger, F. Beck, J. Reinecke, M. Grebenstein, M. Hutter, and J. Lee, "Maximum Stiffness of Impact-Robust Actuators in Highly Dynamic Robotics Tasks: Application to Series Elastic Actuator Design",  IEEE Robotics and Automation Letters, 2026. doi: [https://doi.org/10.1109/LRA.2026.3710324].
- [3] A. Shu, C. Raschel, M. Keppler, A. Wedler, and M. Görner, "Impact Robustness Versus Torque Bandwidth: A Design Guide for Differential Elastic Actuators", IEEE Transactions on Robotics, vol. 40, pp. 3657–3675, 2024, doi: [https://doi.org/10.1109/TRO.2024.3422049].
